# Gate G3.2: Intake Trust Review

**Status:** Approved

**Review date:** 2026-09-11

**Decision:** Approved

**Decision owner:** Project owner

## Scope reviewed

Gate G3.1 authorized Step 3.2 only. This review covers capsule selection,
pre-import safety boundaries, accepted-manifest review, bounded rejection,
observed incident orientation, environment comparison, evidence lineage,
exclusions, missing-evidence status, responsive layout, and keyboard behavior.

It does not cover redesign of the hypothesis map, experiment inspector, or
reproduction proof. It introduces no provider changes.

## Evidence

| Criterion | Evidence | Result |
|---|---|---|
| User knows what will enter | Intake names the ZIP and seed paths plus the four mandatory checks | Pass |
| User knows what stays out | Safety panel states no production connection; overview lists all explicit exclusions | Pass |
| Rejection is understandable | Bounded reason and no-evidence-accepted notice receive focus | Pass |
| Accepted evidence is inspectable | Every included item shows ID, path, provenance, size, and redaction state | Pass |
| Observations are distinct from inference | Overview uses observed labels and contains no hypothesis or confidence claim | Pass |

## Known limitations

1. Capsule schema 1.0 supplies a prose observed summary, not a structured
   incident timeline.
2. Progress state is not yet represented by reloadable routes.
3. Hypothesis and proof views retain the Phase 2 presentation.
4. Exact device and assistive-technology validation remains pending.
5. Previously recorded provider limitations and cancellation debt remain open.

## Recommendation

Approve Gate G3.2 and authorize Step 3.3 only: implement the hypothesis map and
experiment inspector against the approved experience foundation. Keep the
reproduction-proof redesign, provider changes, and unsupported pause or exclude
controls outside that authorization.
