**Status:** Approved

**Review date:** 2026-09-11

**Decision:** Approved

**Decision owner:** Project owner

## Scope reviewed

Gate G2.1 authorized Step 2.2 only. This review covers the public capsule
schema, seeded proxy-identity capsule, directory and ZIP ingestion, bounded
validation, sensitive-content screening, content-addressed storage,
normalized persistence, API endpoints, and accepted or rejected browser
states.

## Evidence

| Criterion | Evidence | Result |
|---|---|---|
| Capsule format is explicit | Published JSON Schema version `1.0` and strict runtime models | Pass |
| Seed remains synthetic and sanitized | Five project-created evidence files using TEST-NET-2 addresses and public URLs | Pass |
| Unsafe paths cannot escape the capsule | Traversal, absolute, non-normal, duplicate, control-character, backslash, and symlink paths fail closed | Pass |
| Resource use is bounded | Streaming request, expanded-size, file-count, manifest-size, and evidence-size limits | Pass |
| Manifest and files cannot silently diverge | Exact declared-file set, byte-size, media-type, and SHA-256 checks | Pass |
| Malformed structured evidence fails closed | UTF-8, null-byte, duplicate-key, finite-number, and JSON parsing controls | Pass |
| Obvious secrets are not accepted | Credential and local-path patterns reject before artifact storage | Pass |
| Accepted evidence retains lineage | API and browser preserve evidence ID, hash, size, media type, provenance, and redaction status | Pass |
| Persistence supports multiple capsules | Evidence keys are capsule-scoped and the schema migration retains earlier rows | Pass |
| Rejections do not echo unsafe content | Stable error codes and fixed messages are returned | Pass |
| Product path works locally | Browser seed import, accepted-evidence display, API lookup, and SQLite storage completed successfully | Pass |
| Sponsor infrastructure remains off | No live provider client or request is involved in import | Pass |

## Known limitations

1. Sensitive-content patterns cannot guarantee discovery of every possible
   secret or personal-data format.
2. Artifact retention and deletion policy remain unresolved technical debt.
3. Browser directory selection is not supported. Browser users upload ZIP
   capsules or select the allowlisted seed.
4. Capsule acceptance does not yet create hypotheses or an investigation.
5. Provider planning remains disabled.

## Recommendation

Approve Gate G2.2 and authorize Step 2.3 only: create evidence-linked,
mutually exclusive hypotheses through a deterministic local planning adapter,
persist the initial investigation and its events, and connect the bounded
Nemotron adapter behind the same contract.

Do not authorize a live Nemotron request through this decision. Any live
product-path request requires its own bounded execution review.
