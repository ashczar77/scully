## Decisions and tradeoffs

React and TypeScript are selected because the product now requires a stateful
investigation timeline, branching views, and frequent partial updates. Node.js
is only frontend build and test tooling. It is not an application-server or
capsule requirement.

SQLite and a single in-process worker favor delivery speed over horizontal
scale. The interfaces preserve replacement paths, but replacing them is not
part of the hackathon build unless measurements prove it necessary.

The first vertical slice uses local deterministic adapters. This lets the team
build and test the product workflow before provider latency, spend, or access
can block progress.
