## Alternatives and trade-offs

### Treat the Pragtig name as fully cleared now

This would simplify early naming, but the adjacent Pracht framework and
incomplete trademark, registry, domain, and identifier searches make full
approval premature.

### Rename immediately

This would avoid current collision risk, but selecting another name without
the same structured research could reproduce the problem.

### Selected naming approach

Use Pragtig, pronounced prakh-tik, as the selected provisional working name
and complete structured clearance before public branding.

### Select the MIT License

MIT would reduce administrative text but lacks the same explicit patent grant.

### Selected license approach

Propose Apache License 2.0 for its permissive adoption terms, explicit patent
language, and familiarity in the Java framework ecosystem.
