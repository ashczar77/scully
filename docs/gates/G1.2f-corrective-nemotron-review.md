## Root cause

The selected Nemotron model reasons by default before producing its final
response. Attempt 002 used all 1,024 allowed output tokens and did not reach a
usable tool call. NVIDIA recommends a larger output allowance and tool-specific
sampling parameters for this model. Output-budget exhaustion is the
evidence-backed cause. The account, credential, endpoint, and model setup are
working.
