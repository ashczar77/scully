## Known limitations

1. Run 001 did not retain precise provider usage or a specific Nemotron failure
   category. The corrected diagnostics apply only to future runs.
2. Nemotron live repeatability is supported by the earlier capability evidence
   and one complete sponsor-path success, not two identical live product runs.
3. The Sandbox reported-cost unit remains undocumented.
4. The Sandbox SDK exposes no supported cleanup method for the untagged states.
5. Explicit remote cancellation remains known technical debt. Provider timeout
   plus local deadlines remains the approved fallback.
6. Direct target-engineer validation remains deferred.

## Decision

Gate G4.4 is approved. The combination of two equivalent local proof runs, a
successful clean-checkout audit, one complete live sponsor-stack run, bounded
measurements, and preserved failure evidence is sufficient for the release
proof.

No additional provider run is required. Step 4.5 feature freeze is authorized.
It must resolve release-blocking defects, establish the accepted and deferred
scope, finalize the architecture and threat-boundary records, and prepare a
release candidate for submission work.
