# Gate G1.3: Execution Integrity Review

**Status:** Accepted with explicit limitation

**Phase:** 1, Sponsor-stack and architecture feasibility

**Step:** 1.3, Prove isolation and deterministic evaluation

**Decision date:** 2026-09-11

**Reviewer:** Project owner

## Decision

Accept the execution-integrity evidence with explicit cancellation retained as
known technical debt. Do not approve or run another termination probe. Move
directly into the working product.

## Evidence accepted

- Two experiment branches inherited one common parent and remained isolated.
- Deterministic code, not a model response, controlled reproduction verdicts.
- The incident observation matched its fixed signature.
- The known-good observation did not match the incident signature.
- Provider-side command timeout reached its expected terminal state.
- Timeout and cancellation outcomes remain evaluator-inconclusive.
- Failed termination attempts stopped within their reviewed request and
  operation bounds.
- The second termination attempt observed a terminal state after its explicit
  cancellation request, leaving no unexplained active operation.

## Limitation and fallback

The project has not proven that the explicit cancellation path reports the
exact expected `CANCELLED` state with valid retention and duration metadata.
That gap does not justify another infrastructure probe under the current
schedule.

The initial product will:

1. rely on the proven provider command timeout as the remote execution bound;
2. enforce a separate local observation deadline;
3. stop accepting new work when the local deadline expires;
4. mark the run timed out or termination-unconfirmed rather than successful;
5. keep explicit cancellation disabled or best-effort until revisited;
6. preserve the fixed operation, output, and retry limits already tested.

## Deferred technical debt

| Item | Required action | Revisit by |
|---|---|---|
| Exact explicit-cancellation semantics | Run an instrumented probe only after a new review | Before production readiness |
| Cancellation failure reason in live evidence | Use the bounded reason codes already implemented | With any future probe |
| Sandbox state retention policy | Define retention and cleanup ownership | Gate G2.4 |
| Sandbox reported-cost unit | Confirm the provider unit before cost reporting | Gate G2.5 |

## Authorization

This decision authorizes implementation architecture and product-foundation
work. It does not authorize another termination probe or broaden live provider
access.
