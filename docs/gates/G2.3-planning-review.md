## Known limitations

1. Local planning supports only the seeded proxy incident.
2. Nemotron product-path repeatability remains unproven.
3. Structural primary-cause grouping does not prove semantic exclusivity.
4. Branch execution and deterministic signature evaluation are not yet part of
   the working product.
5. Timeout, retry, streaming, and terminal execution states remain Step 2.4
   work.
6. Explicit cancellation remains known technical debt and no further
   termination probe is approved.
7. Capsule artifact retention policy, Sandbox state retention, and the
   provider-reported cost unit remain unresolved.
8. Tavily URL deduplication and overage-status checks remain required before
   expanded retrieval use.

## Recommendation

Approve Gate G2.3 and authorize Step 2.4 only: execute the three app-owned
variants through a deterministic local adapter, persist branch events, and
evaluate the declared failure signature without model authority over the
verdict. Keep the Sandbox adapter behind the same contract and disabled by
default.

Do not authorize a live Sandbox request through this decision. Any live
product-path request requires a separate bounded execution review. Continue
to use provider timeouts plus local deadlines as the initial fallback, and do
not run another termination probe.
