## Result

Attempt `g1.2-sandbox-001` succeeded using `python:3.12-slim`. The common
parent wrote a fixed synthetic marker. Both children read that marker, while
the second child confirmed that the first child's new file was absent.

The redacted evidence is stored in
`validation/results/g1.2-sandbox-probe-001.json`.

## Interpretation

The project adapter, authentication, strict image resolution, direct command
execution, persistence, branching, result normalization, operation counting,
and evidence redaction worked together. The successful sibling check proves
the branch behavior needed for the hypothesis-experiment design at this scale.

Three untagged synthetic result states were observed. The installed SDK does
not expose a public image-delete operation, so explicit cleanup remains an
architecture concern. The result does not establish timeout, cancellation, or
deterministic signature-evaluator behavior, which remain in Step 1.3.

## Recommendation

Approve ConTree branching as a proven sponsor primitive. Authorize the G1.2
primitive capability review, which will evaluate Nemotron, Tavily, and Sandbox
together and confirm their roles, limitations, and fallbacks. Do not authorize
additional live provider calls at this checkpoint.
