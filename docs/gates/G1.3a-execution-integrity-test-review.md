## Decisions and tradeoffs

The first live attempt proves branch isolation and evaluator authority using
fixed observations. It intentionally does not install the full Express fixture.
That keeps the test focused on Step 1.3 mechanics and leaves full capsule-to-
reproduction integration for Phase 2.

Timeout and explicit cancellation are separated from the first live attempt.
This prevents a single approval from authorizing a larger, harder-to-audit
operation set and avoids treating the SDK's internal cleanup as independent
proof of user cancellation.
