## Decisions and tradeoffs

- Inject the narrow client surface instead of importing provider packages at
  module import time. This keeps offline tests deterministic.
- Treat unrecognized or incomplete external responses as contract failures.
- Store Tavily snippets in the provider outcome for later evidence processing,
  but exclude them from usage measurements.
- Use direct ConTree command arguments and require absolute executables.
- Defer SDK exception translation and failed-operation measurement to the probe
  runner, where timing and retry policy can be handled consistently.
