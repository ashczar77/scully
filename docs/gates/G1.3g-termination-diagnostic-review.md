## Decisions and tradeoffs

The correction retains a small semantic code instead of a provider message.
This distinguishes the only remaining safe contract checks without expanding
the evidence boundary. Unknown failures continue to retain only their error
type and bounded counters.

The prior result cannot be retroactively assigned a reason. A new attempt is
required to observe the mismatch through the corrected instrumentation.

## Proposed execution boundary

The proposed execution is `g1.3-termination-003` exactly once. It preserves
the approved two disposable operations, fixed image and commands, timeout and
cancellation behavior, polling limits, exact-ID cleanup, transport limits,
redaction rules, stop-on-first-failure behavior, and zero-retry policy.

No Nemotron request, Tavily search, unrelated Sandbox operation, or automatic
retry is included.
