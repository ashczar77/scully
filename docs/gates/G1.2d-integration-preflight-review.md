## Decisions and tradeoffs

- Pin exact direct versions and retain a resolved lock for the tested Python
  environment.
- Use the provider packages only in the client-construction module. The
  preflight itself has no provider SDK import.
- Set model retries to zero so one approved call cannot become several billable
  attempts.
- Keep the Sandbox operation budget at one until its separate execution review.
- Treat `SCULLY_ENABLE_LIVE` as the explicit reviewed-execution switch.
