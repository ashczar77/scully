## Known limitations

1. The local executor simulates the seeded failure and is not yet the exported
   runnable reproduction package.
2. SSE currently replays completed persisted events instead of streaming
   progressive updates during synchronous local execution.
3. Live Sandbox product-path behavior, timeout repeatability, cleanup, and
   retention remain unproven.
4. Explicit remote cancellation remains known technical debt. No further
   termination probe is approved.
5. The Sandbox reported-cost unit remains undefined.
6. Nemotron requires further repeatability evidence.
7. Tavily URL deduplication and overage-status checks remain unresolved.

## Recommendation

Approve Gate G2.4 and authorize Step 2.5 only: package the deterministic proxy
fixture as a runnable failing test, connect the complete local product flow,
add progressive diagnostic presentation where useful, and record end-to-end
latency and limitations.

Keep provider features disabled by default. A live Sandbox product-path
request requires a separate bounded execution review. Continue to use provider
timeouts plus local deadlines as the initial fallback, and do not run another
termination probe.
