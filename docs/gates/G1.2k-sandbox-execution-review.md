No Sandbox image resolution or command ran.

## Known limitations

- A successful lifecycle can leave three untagged synthetic image states. The
  installed SDK exposes no public delete method.
- The SDK can retry a rate-limited operation submission internally within the
  configured timeout. The runner itself has no retry loop.
- The public result exposes elapsed time and a reported cost value, but does
  not label that cost's unit. The first result will retain the numeric value
  without interpreting it as dollars or credits.
- Formal timeout, cancellation, and evaluator integrity remain in Step 1.3.
