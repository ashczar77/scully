# Scully

Scully is a hackathon project that turns
sanitized production-incident evidence into an executable reproduction without
giving AI unrestricted production access.

The concept is in problem and boundary validation. See the
[hackathon project plan](docs/HACKATHON_PROJECT_PLAN.md) and
[project documentation](docs/README.md) for its status and roadmap.
